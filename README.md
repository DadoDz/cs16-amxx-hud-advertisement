# HUD Advertisement

A lightweight HUD advertisement system for **Counter-Strike 1.6** servers.
The plugin displays random colorful HUD advertisements/messages loaded from a configuration file at random intervals.

## Plugin Information

  - **Name**: HUD Advertisement
  - **Version**: 1.0
  - **Author**: DadoDz
  - **Game**: Counter-Strike 1.6

## Installation
1. Place ```hud_advertisement.ini``` in: **addons/amxmodx/configs**
2. Place ```hud_advertisement.sma``` in: **addons/amxmodx/scripting/**
3. Compile it with your AMXX compiler.
4. Place the compiled .amxx file in: **addons/amxmodx/plugins/**
5. Add this line to your plugins.ini: ```hud_advertisement.amxx```
6. Restart your server.
